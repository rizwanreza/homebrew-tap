# homebrew-tap

Homebrew tap for [smartly](https://github.com/rizwanreza/smartly-cli).

```
brew install --no-quarantine rizwanreza/tap/smartly
```

The binaries aren't signed with an Apple Developer ID yet, so
`--no-quarantine` avoids a macOS Gatekeeper block. Already blocked? Run
`xattr -d com.apple.quarantine "$(brew --prefix)/Caskroom/smartly/"*/smartly`
instead of clicking "Move to Trash".

Casks here are generated by GoReleaser on each smartly release.
